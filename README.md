# Internet Television Service
A REST API for an IPTV service developed with Spring Boot.

## Technologies

- Java 17
- Spring Boot 3.4.5
- Spring Web
- Spring Data JPA
- H2 Database
- Lombok
- OpenAPI / Swagger UI
- Maven

## Description

This project provides REST API endpoints for an IPTV service.

The application was developed as a university project to practice building REST APIs with Spring Boot, working with JPA entities and database persistence.

The application uses an H2 in-memory database for data storage and provides API documentation through OpenAPI and Swagger UI.

## API Documentation

Once the application is running, the API documentation is available through Swagger UI.

## Running the Application

The project uses Maven and requires Java 17 or later.

The application uses an H2 in-memory database, so no external database server is required.
